# 日志导出格式

## 1. 为什么日志重要

上位机项目最有价值的不是按钮，而是日志。日志能证明你发送了什么、收到了什么、什么时候超时、CRC 是否正确、解析结果是什么。

面试时，有原始 TX/RX 日志，比只说“我调通过 Modbus”更有说服力。

## 2. 推荐 CSV 字段

| 字段 | 示例 | 说明 |
|---|---|---|
| `time` | `2026-06-04 14:20:01.120` | 时间戳 |
| `direction` | `TX` 或 `RX` | 发送或接收 |
| `port` | `COM5` | 串口号 |
| `frame_hex` | `01 03 00 00 00 02 C4 0B` | 原始十六进制帧 |
| `result` | `CRC_OK`、`TIMEOUT` | 处理结果 |
| `message` | `read holding registers` | 简短说明 |

## 3. 日志样例

```csv
time,direction,port,frame_hex,result,message
2026-06-04 14:20:01.120,TX,COM5,"01 03 00 00 00 02 C4 0B",SENT,"read holding registers"
2026-06-04 14:20:01.138,RX,COM5,"01 03 04 00 64 00 C8 BA 7A",CRC_OK,"regs[0]=100 regs[1]=200"
2026-06-04 14:20:05.500,TX,COM5,"01 06 00 01 04 D2 5B 56",SENT,"write single register"
2026-06-04 14:20:06.000,RX,COM5,"",TIMEOUT,"no response in 500 ms"
```

## 4. 导出策略

- 每次发送请求都记录 TX。
- 每次接收数据都记录 RX。
- CRC 错误、超时、异常响应都要记录。
- 导出文件名建议带日期，如 `modbus_log_20260604.csv`。
- 不要只保存解析后的数值，原始帧必须保留。

## 5. 简历表达

> 在 Qt 上位机中设计 TX/RX 日志导出格式，记录时间戳、方向、串口号、原始十六进制帧、CRC 结果和解析说明，用于 Modbus 通信问题复盘和面试展示。
