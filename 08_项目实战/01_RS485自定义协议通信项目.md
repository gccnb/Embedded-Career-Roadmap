# RS485 自定义协议通信项目

## 1. 本节要解决什么问题

本节要解决的问题是：用 # 帧尾、自定义命令和 RS485 收发做第一个通信项目。它更接近项目收尾和求职表达阶段：不仅要能写代码，还要能把调试过程、模块边界和项目价值讲清楚。

对初学者来说，不要把上位机、项目实战或面试准备看成最后临时补的东西。它们应该从学习早期就开始积累：每写一个功能，就留下日志；每解决一个问题，就写复盘；每完成一个模块，就尝试改写成简历表达。

## 2. 基本概念

RS485 自定义协议通信项目 可以理解为把底层知识组织起来的方法。单片机负责采集和控制，RS485/Modbus 负责通信，FreeRTOS 负责任务拆分，Qt 或面试文档负责展示和表达。

概念学习不要停留在“知道名词”。你要能说明它和项目中哪些模块有关，输入输出是什么，失败时如何定位。

## 3. 工程用途

项目实战的重点不是编造“大项目”，而是把公开可复现的学习内容做成闭环：需求、协议、代码、调试、问题、复盘、简历表达。不要写真实公司、客户或产线信息。涉及接线、控制卡、驱动器、传感器时必须查数据手册、原理图和实测结果。

如果你做的是个人学习项目，要明确写“个人项目”或“课程外实践”。公开资料库中只能使用抽象工业控制、机器视觉控制、串口调试等场景，不得泄露真实公司、客户、产线和设备内部资料。

## 4. 简单代码或伪代码

下面示例只表达流程，不代表真实项目协议，也不绑定具体公司或设备。

```text
需求 -> 接线核对 -> 协议设计 -> 代码实现 -> 日志记录 -> 问题复盘 -> 简历表达
```

阅读这段示例时，重点不是语法，而是看清楚每一步留下了什么证据：输入、处理、输出、日志和复盘。

## 5. 常见错误

- 项目目标太大，最后没有一个能演示的闭环。
- 写了真实公司或设备细节，违反公开资料边界。
- 只讲最终效果，不记录调试过程。
- 没有把项目拆成模块，面试时讲不清职责。
- 简历表达过于空泛，面试官追问时没有细节支撑。

这些错误都可以通过“保留原始日志、写清楚调试步骤、只写自己能解释的内容”来避免。

## 6. 调试方法

调试时建议把过程写成表格：时间、现象、输入、输出、怀疑点、验证方法、结论。Qt 上位机要保存 TX/RX 原始帧；项目实战要保存接线依据、协议说明和测试步骤；面试准备要把问题复盘成 1 分钟回答。

涉及控制卡、驱动器、传感器、端子定义或接线时，必须以数据手册、原理图和实测结果为准，不能凭经验编造。

## 7. 面试常问问题

1. 问：RS485 自定义协议通信项目 能体现什么工程能力？
   答：它体现把底层代码、通信协议、调试过程和项目表达串起来的能力，不只是会写一个函数。
2. 问：如果面试官追问细节，你怎么回答？
   答：按“需求、实现、调试、问题、改进”回答，并拿出自己能解释的日志或代码片段。
3. 问：如何避免项目描述夸大？
   答：只写自己完成和验证过的内容，学习项目就写学习项目，不写真实公司交付和客户信息。

## 项目展示化补充

### 项目结构

```text
rs485_custom_protocol/
├── app_main.c          主循环和状态调度
├── uart_driver.c       串口收发接口
├── rs485_driver.c      RS485 方向控制
├── protocol.c          自定义协议组帧和解析
├── protocol.h          命令字、缓冲区长度和接口声明
└── logs/               调试记录和测试帧样例
```

### 运行流程

```text
串口接收中断收到字节
-> 放入 rxBuffer
-> 遇到 # 后置位 rxFlag
-> 主循环发现 rxFlag
-> 校验帧头、帧尾和命令字
-> 执行抽象动作
-> 通过 RS485 回发应答帧
```

这里的“抽象动作”可以是模拟状态切换、模拟参数设置或模拟设备查询，不要写成真实设备控制流程。涉及真实端子、控制卡或传感器时，仍然要以数据手册、原理图和实测结果为准。

### 测试用例

| 测试项 | 输入帧 | 期望结果 |
|---|---|---|
| 正常命令 | `$MODWA#` | 回发确认帧，日志记录 TX/RX |
| 错误帧尾 | `$MODWA!` | 不置位完整帧标志 |
| 未知命令 | `$HELLO#` | 返回错误提示或记录未知命令 |
| 超长输入 | 连续输入超过缓冲区长度 | 清空缓冲区并记录溢出 |

### 调试日志样例

```text
[10:21:03.120] RX 24 4D 4F 44 57 41 23  ($MODWA#)
[10:21:03.122] PARSE cmd=MODWA result=OK
[10:21:03.125] TX 24 4F 4B 23           ($OK#)
```

面试时可以围绕这条日志说明：中断如何收字节、主循环如何识别完整帧、为什么要保留十六进制原始数据。
