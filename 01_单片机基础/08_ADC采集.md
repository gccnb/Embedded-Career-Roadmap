# ADC 采集

## 1. 本节要解决什么问题

本节要解决的问题是：单片机如何把外部模拟电压转换成程序可以处理的数字量。

很多初学者学 ADC 时只记住一句话：“ADC 是模数转换”。这不够。工程里真正要回答的是：传感器输出的电压怎么进单片机？采样值为什么会抖？采样周期怎么选？采到的数字量怎么换算成电压、温度、压力或位置？如果数值不对，应该先查代码还是先查硬件？

ADC 是单片机基础里非常常见的外设。它和 GPIO、定时器、USART、PWM 一起，构成很多控制类项目的底层能力。比如读取电位器、检测电池电压、采集传感器模拟量，再通过串口、RS485 或 Modbus RTU 上报给上位机。

## 2. 基本概念

ADC 的全称是 Analog-to-Digital Converter，中文叫模数转换器。它把一个连续变化的模拟电压转换成离散的数字值。

常见 ADC 参数如下：

| 参数 | 含义 | 工程中关注什么 |
|---|---|---|
| 分辨率 | ADC 能输出多少级数字量，如 12 位是 0 到 4095 | 分辨率越高，理论上能分得越细 |
| 参考电压 | ADC 换算的基准电压 | 换算公式必须和参考电压一致 |
| 采样时间 | ADC 对输入信号采样的时间 | 太短可能采不准，太长会降低速度 |
| 通道 | ADC 可以采集的输入引脚 | 通道号要和原理图、芯片手册一致 |
| 触发方式 | 软件触发、定时器触发、DMA 连续采样等 | 决定采样是否稳定、是否占 CPU |

以 12 位 ADC、参考电压 3.3 V 为例，原始值 `adcRaw` 换算成电压：

```text
voltage = adcRaw * 3.3 / 4095
```

注意这只是理想公式。真实项目中还要考虑参考电压精度、分压电阻误差、传感器误差、输入阻抗、滤波电路和 PCB 噪声。

## 3. 工程用途

ADC 常用于读取模拟传感器或模拟状态量。比如：

- 电位器位置采集；
- 电池电压检测；
- 模拟温度、压力、光照传感器采集；
- 电机电流或母线电压检测；
- 工业控制中模拟量输入模块的基础理解。

在求职项目里，ADC 可以和通信项目结合起来：单片机采集一个模拟量，经过滤波和阈值判断，再通过 USART、RS485 或 Modbus RTU 上报给 Qt 上位机。这样项目就不只是“串口发固定字符串”，而是有了采集、处理、通信、显示的链路。

涉及真实传感器、分压电路、控制卡端子、模拟量输入模块时，必须以数据手册、原理图、端子定义和实测结果为准。不要凭经验编造输入范围、接线方式或转换公式。

## 4. 简单代码或伪代码

下面示例不依赖具体芯片库，只表达 ADC 采集后的处理思路。

```c
#include <stdint.h>

#define ADC_MAX_VALUE   4095.0f
#define ADC_REF_VOLT    3.3f

static uint16_t adcBuffer[8];
static uint8_t adcIndex = 0;

float adc_raw_to_voltage(uint16_t raw)
{
    return (float)raw * ADC_REF_VOLT / ADC_MAX_VALUE;
}

uint16_t adc_filter_average(uint16_t newValue)
{
    uint32_t sum = 0;

    adcBuffer[adcIndex] = newValue;
    adcIndex++;
    if (adcIndex >= 8) {
        adcIndex = 0;
    }

    for (uint8_t i = 0; i < 8; i++) {
        sum += adcBuffer[i];
    }

    return (uint16_t)(sum / 8);
}

void adc_task_polling(void)
{
    uint16_t raw = adc_read_once();          /* 伪函数：读取一次 ADC */
    uint16_t filtered = adc_filter_average(raw);
    float voltage = adc_raw_to_voltage(filtered);

    if (voltage > 2.5f) {
        status_set_alarm();                  /* 伪函数：设置告警状态 */
    }
}
```

这段代码表达三个要点：先读原始值，再做简单滤波，最后换算并参与状态判断。工程中 `adc_read_once()` 要替换成具体芯片库函数或驱动接口。

## 5. 常见错误

1. 公式写错。12 位 ADC 最大值通常按 4095 计算，不要写成 4096 后又解释不清。
2. 参考电压搞错。代码里写 3.3 V，但板子实际参考电压可能不是 3.3 V。
3. 通道选错。程序读的是 ADC 通道 1，原理图上传感器接在 ADC 通道 3。
4. 不滤波。模拟量轻微抖动很常见，直接用单次采样做阈值判断容易误触发。
5. 不看输入范围。传感器输出超过单片机 ADC 允许电压，可能损坏芯片。
6. 把 ADC 数值不稳全归咎于代码，忽略地线、参考电压、输入阻抗和噪声。

## 6. 调试方法

调试 ADC 要同时看软件和硬件。

| 现象 | 可能原因 | 排查方法 |
|---|---|---|
| ADC 一直是 0 | 引脚没配置、通道错、输入接地 | 查原理图和通道配置，用万用表测输入电压 |
| ADC 一直满量程 | 输入超过参考电压、引脚悬空、接线错误 | 测输入电压，确认没有超过芯片手册限制 |
| 数值抖动明显 | 噪声、采样时间短、没有滤波 | 增加平均滤波，检查地线和参考电压 |
| 换算电压不对 | 参考电压、分压比例或公式错误 | 用万用表实测并反推公式 |

建议调试顺序：

1. 先用万用表测 ADC 引脚实际电压。
2. 再打印 ADC 原始值，不要一开始只看换算后的工程量。
3. 用固定电压输入测试 0 V、约一半参考电压、接近参考电压。
4. 加入平均滤波后，对比滤波前后的波动范围。
5. 如果后续通过 Modbus 上报，要同时保存原始 ADC 值和上报帧。

## 7. 面试常问问题

1. 问：ADC 是什么？
   答：ADC 是模数转换器，把外部模拟电压转换成数字量，程序再根据数字量进行换算、判断或上传。

2. 问：12 位 ADC 采到 2048，大约是多少电压？
   答：如果参考电压是 3.3 V，理想情况下约为 `2048 * 3.3 / 4095`，接近 1.65 V。

3. 问：ADC 数值抖动怎么办？
   答：先确认硬件输入和参考电压稳定，再从软件上做平均滤波、中值滤波或限幅滤波，不能只靠猜。

4. 问：采样时间为什么重要？
   答：采样时间太短时，ADC 内部采样电容可能没有充分充电，尤其在输入阻抗较高时会导致采样不准。

5. 问：ADC 项目怎么和通信项目结合？
   答：可以采集模拟量，做滤波和阈值判断，再通过 USART、RS485 或 Modbus RTU 上报给上位机，这样能体现采集、处理、通信和调试闭环。

## 8. 简历表达方式

> 使用 ADC 完成模拟量采集和简单平均滤波，实现原始采样值到电压值的换算，并结合串口/RS485 通信上报采集结果，能够根据原理图、数据手册和实测电压定位采样异常问题。

这句话适合学习项目。不要写成真实工业采集系统，除非你确实有可公开、可证明的项目背景。

## 9. 小练习

1. 假设 12 位 ADC 参考电压为 3.3 V，计算原始值 1000、2048、3000 对应的理想电压。
2. 写一个 10 次平均滤波函数，输入 ADC 原始值，输出滤波后的原始值。
3. 设计一个阈值告警逻辑：电压大于 2.5 V 置位告警，小于 2.3 V 清除告警。
4. 思考如何把 ADC 采集值打包进 Modbus RTU 保持寄存器。

## 10. 小结

ADC 是单片机从外部世界获取模拟信息的重要入口。学习 ADC 时，不要只背“模数转换”，要能讲清楚通道、参考电压、分辨率、采样时间、滤波、换算和调试方法。把 ADC 和 RS485/Modbus、Qt 上位机结合起来，就能形成更完整的嵌入式求职项目链路。
